# click-browser-appkit

build tool for modern workflows

### Disclaimer:
This is based on great work by [Community Project], with the gem [endpoints.py]. 
Built out of necessity for a project that needed partial.ejs support.

### Other acknowledgements:

* [endpoints.py] - Fast processor
* [partial.ejs] - Additional support

## Dependencies

* Java Virtual Machine required
* endpoints.py >= 1.4.0
* partial.ejs >= 3.0.0

## Install

```
gem install click-browser-appkit
```

## Using click-browser-appkit

```
Usage: click-browser-appkit [options]

Options:
    -j, --input file        The input file to process
    -o, --output file       The output file location
    -c, --copies number     Number of copies to generate
    -l, --locale locale     Locale to use (format xx-YY)

Common options:
    -h, --help              Show this message
        --version           Show version
```
